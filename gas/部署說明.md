# AI 解析服務：Google Apps Script 部署說明（Gemini）

網頁的「AI 自動解析」不在瀏覽器保存 API Key，而是透過您自己部署的 Google Apps Script 轉送到 Google Gemini API。
預設模型：`gemini-3.1-flash-lite`（Gemini 3.1 Flash-Lite，低成本、低延遲，支援圖片與 PDF 輸入及 JSON 結構化輸出）。

## 一、申請 Gemini API Key
到 Google AI Studio：https://aistudio.google.com/apikey →「建立 API 金鑰」。

## 二、建立專案
1. 到 https://script.google.com/ → 「新專案」，命名例如「起重機申請 AI 解析」。
2. 把 `Code.gs` 的內容整份貼上，取代預設程式碼，儲存。

## 三、設定指令碼屬性
左側齒輪「專案設定」→ 最下方「指令碼屬性」→ 新增：

| 屬性 | 值 |
|---|---|
| `GEMINI_API_KEY` | 第一步取得的 Gemini API Key |
| `ACCESS_TOKEN` | 自訂一組不易猜的存取碼（例如 20 碼英數），網頁端要填相同的值 |
| `MODEL`（選填） | 預設 `gemini-3.1-flash-lite`；要更準可改用其他 Gemini 模型代碼 |
| `THINKING`（選填） | `minimal`／`low`／`medium`／`high`，預設 `low`；荷重表判讀不準時可改 `medium` |
| `DAILY_LIMIT`（選填） | 每日 AI 解析次數上限，預設 `500`（台灣時間每日 0 點重置）；填 `0` 表示不限制 |

每日計數存在指令碼屬性 `COUNT_日期`（自動只保留 7 天）；在編輯器執行函式 `showUsage` 可於「執行記錄」看到今日已用次數。

可在編輯器選擇函式 `testApiKey` → 執行，於「執行記錄」看到 `200` 即表示 Key 與模型可用（第一次執行需授權「連線至外部服務」）。

## 四、部署為網頁應用程式
1. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 部署後複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
4. 之後修改程式碼要生效，需「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」。（只改指令碼屬性不必重新部署。）
   ⚠ 更新 `Code.gs`（例如加入每日上限）後務必依此步驟發布「新版本」，網址不會改變，網頁不用改。

## 五、網頁端設定
網頁應用程式網址與存取碼固定寫在 `hub/ai.js` 的 `DEFAULT_URL`、`DEFAULT_TOKEN`。
更換存取碼（例如外流時）：先改 Apps Script 指令碼屬性 `ACCESS_TOKEN`，再改 `hub/ai.js` 的 `DEFAULT_TOKEN` 並重新上傳網站。

## 注意
- 存取碼是唯一的保護，請勿公開；外流時到指令碼屬性更換即可。
- API 費用由該 Google 帳戶的 Gemini API 計費（免費層級的資料可能被 Google 用於改善產品，含個資的證件建議使用付費層級）。
- 單次解析約 10–60 秒；檔案越大越久。PDF 建議 20 MB 以內。
